# HR Analytics Project Using Python

## Project Overview

This project analyzes employee and salary data using Python, Pandas, and Matplotlib.

The objective is to generate HR insights such as employee count, salary analysis, department-wise metrics, and data visualization.

---

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## Dataset Information

The dataset contains:

- Employee ID
- Employee Name
- Department
- Salary

Departments included:

- HR
- Finance
- Sales
- IT

---

## Analysis Performed

### Employee Analysis

- Total Employee Count
- Department-wise Employee Count

### Salary Analysis

- Average Salary
- Highest Salary
- Lowest Salary
- Department-wise Average Salary

### Visualization

- Average Salary by Department Bar Chart

---

## Key Findings

- Total Employees: 8
- Highest Salary: ₹80,000
- Lowest Salary: ₹40,000
- IT Department has the highest average salary.
- HR Department has the lowest average salary.
